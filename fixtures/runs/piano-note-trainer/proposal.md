# Piano note-reading trainer

| Field | Value |
| --- | --- |
| kind | tool |
| audience | Adult beginners and children practising with a parent, in short daily sessions of a few minutes |
| tone | playful, calm, encouraging |
| density | balanced |
| motion | 1 (gentle right/wrong feedback only) |
| dark_mode | light-first |
| must_have | buttons, chips, card-system |
| mood | playful, minimal, warm |
| languages | en |

## 1. GoShuin: Goshuin Map & Journal for iPhone — safe pick

<https://aestudio.studio/goshuin/en> · [source](https://www.awwwards.com/sites/goshuin-every-stamp-a-memory)

**Why it fits this brief.** A calm, warm learning companion is close to what this app already is: a paged-book landing with a serif title page, paper tones (#f8f3e7) under slate ink (#2d3435), and one bronze accent (#756449) used only for rules. Motion is level 1 and it ships a pause-motion control, which suits a session where nothing should pull the eye off the staff. The Previous / page / Next paging bar also maps well onto "next note" pacing. It is airy, not dense, so the exercise screen gets plenty of room.

**What to take**
- palette — paper #f8f3e7, slate ink #2d3435, bronze #756449 kept for rules and focus, which gives a warm light-first base that isn't default cream
- type pairing — Georgia display over system sans (open: Source Serif 4 + Inter); serif for note names and explainer headings, sans for UI
- buttons — the calm pager controls; they need to be scaled up into large tap targets for kids

**What to leave** — the pixel-dithered Japanese pattern art, and the underlined text links used in place of buttons (the brief needs big filled buttons).

## 2. 一卦 (Yi Gua) — bold pick

<https://yigua.art/?lang=en> · [source](https://www.cssdesignawards.com/sites/yi-gua/50511)

**Why it fits this brief.** It's the only single-purpose *tool* in the shortlist, and that matches the "one focused exercise screen" structure: one centred symbol, a serif sentence, one black pill button, hairline rules framing the header and footer. Put a staff where the symbol is and a keyboard where the pill is, and the layout is mostly there. Warm paper (#f3f0e8) with near-black ink (#171815) keeps things calm. It uses system fonts only, so it loads fast.

**What to take**
- spacing scale — the generous single-column rhythm around one central object, for the exercise screen
- buttons — a solid black pill as the single primary action ("Next note", "Start")
- palette — #f3f0e8 paper, #171815 ink, #65645e secondary text

**What to leave** — the soft radial glow behind the symbol. Its motion is level 2, one above the budget, so keep only subtle transitions.

## 3. Stash

<https://stash.cool/> · [source](https://www.awwwards.com/sites/stash)

**Why it fits this brief.** This is the only candidate that covers all three must-haves (chips, a card system and buttons) in a balanced-density tool. Its mono meta lines and single highlighter accent show how to make small status labels readable without adding noise, which is what the right/wrong chips need. Its horizontal ruled cards are a good model for the simple progress card.

**What to take**
- chips — compact labelled tags, restyled as "Correct" / "Try again" status chips
- card system — ruled horizontal cards, for the progress card and the explainer-page index
- buttons — the bracketed [ ← ] pager style as secondary controls

**What to leave** — the giant slab wordmark, the brutalist edge, the #ffff00 yellow, and the #8a8a8a grey deks (below 4.5:1).

## 4. ALMADA LABEL

<https://almadalabel.com/> · [source](https://www.awwwards.com/sites/almada-label)

**Why it fits this brief.** A balanced, motion-1 interface built from a plain grotesk with a single italic serif accent. That accent could carry the encouraging voice ("Nice reading!") while the rest of the UI stays quiet. Its ink-filled square button is a clear, high-contrast primary action.

**What to take**
- buttons — the ink-filled primary button, scaled up
- type pairing — grotesk UI with one italic serif for labels (open: Inter + Instrument Serif)

**What to leave** — the full-bleed fashion photography and the spaced wordmark. The real fonts are hidden behind Shopify aliases, so use only the open alternatives.

## 5. Estudio Niksen

<https://estudioniksen.com/> · [source](https://www.awwwards.com/sites/estudio-niksen)

**Why it fits this brief.** One grotesk, black on light grey (#f0f0f0), near-square 2px radii and a plain one-row nav. That's a disciplined base for the short explainer pages: 16/24 body text and 42px headings with tight tracking. Motion is level 1.

**What to take**
- spacing scale — 16/24 body text and a 42px heading step, for the explainer pages
- buttons — plain rectangular buttons on neutral ground

**What to leave** — the newsletter popover over the hero and the arrow on the sign-up link. The strict monochrome also needs warmth from #1 or #2.

## Combinations

- **A: #1 alone** (GoShuin: palette + buttons). A warm paper-and-slate book feel: calm and grown-up, but kind enough for kids.
- **B: typography of #1 + palette of #2 + cards and chips of #3.** A serif-led, warm-paper tool with Stash's ruled cards and status chips. The best fit for every must-have.
- **C: buttons of #1 + palette of #2.** GoShuin's editorial structure in Yi Gua's warm paper with one black pill: the most minimal, with the staff as the only focal point.

Note on "playful": none of the five is tagged playful. The index's taste profile favours editorial and warm-minimal sites. Playfulness will have to come from the copy, rounder radii and a friendly accent colour for the right/wrong chips, not from a reference.
